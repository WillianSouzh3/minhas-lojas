# Minhas Lojas

App Android para gerir pedidos e produtos das lojas Forma, Floralis e Casa Nativa pelo telemóvel/celular.

## Instalar

Baixe a última versão: **[minhas-lojas.apk](https://github.com/WillianSouzh3/minhas-lojas/releases/latest/download/minhas-lojas.apk)**

Ao abrir o arquivo, o Android pede autorização para instalar apps de fontes desconhecidas.

Celular muito antigo (32 bits)? Use [minhas-lojas-armv7.apk](https://github.com/WillianSouzh3/minhas-lojas/releases/latest/download/minhas-lojas-armv7.apk).

## Entrar numa loja

No computador, abra o painel da loja → **App móvel** → **Gerar QR code**. No app, toque em **Adicionar loja → Escanear QR code**.

Este repositório só publica os instaladores; o código do app é privado.
